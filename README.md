## Projects

### 1. Crop and Weed Detection
**Folder:** `01-Crop-Weed-Detection`

**Domain:** Computer Vision / Object Detection  
**Technique:** YOLOv8

**Objective:**  
Detect and classify crops and weeds in agricultural field images to enable precision spraying of pesticides.

**Key Highlights:**
- Used YOLOv8 object detection model
- Dataset of 1300 annotated images (sesame crop + weeds)
- Trained on Google Colab with GPU
- Generated detection results, confusion matrix, and evaluation metrics

---

### 2. Turbofan Engine Remaining Useful Life (RUL) Prediction
**Folder:** `02-Turbofan-RUL-Prediction`

**Domain:** Predictive Maintenance / Regression  
**Technique:** Random Forest, Gradient Boosting, XGBoost

**Objective:**  
Predict the Remaining Useful Life (RUL) of turbofan engines using sensor data from the NASA C-MAPSS dataset.

**Key Highlights:**
- Used NASA C-MAPSS FD001 dataset
- Feature selection and preprocessing of multivariate time series data
- Compared multiple regression models
- Evaluated using RMSE, MAE, and R² Score
